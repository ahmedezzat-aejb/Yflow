## 🎨 **Дизайн и интерфейс**

### **🌅 Стиль:** Cyberpunk/Futuristic
- **Неоновое свечение:** Ярко-голубой (#00f3ff) и неоново-зелёный (#39ff14)
- **Стекломорфизм:** Полупрозрачные карточки с размытием фона
- **Скошенные края:** Кнопки с уникальной формой clip-path
- **Анимации:** Glitch-эффекты на логотипе, пульсирующие элементы
- **Шрифт:** Orbitron (футуристический моноширинный)

### **📱 Адаптивный дизайн:**
- **Desktop:** Grid layout (2+ колонки)
- **Tablet:** Адаптивная сетка
- **Mobile:** Одноколоночный layout

## 🚀 **Технологический стек**

### **🎯 Frontend:**
- **React 18** - Современная библиотека компонентов
- **TypeScript** - Статическая типизация
- **Tailwind CSS** - Утилитарный CSS фреймворк
- **React Router** - Маршрутизация
- **react-i18next** - Интернационализация

### **⚙️ Backend:**
- **NestJS** - Node.js фреймворк
- **TypeORM** - ORM для базы данных
- **PostgreSQL** - Реляционная база данных
- **JWT Authentication** - Аутентификация

### **🔧 DevOps:**
- **GitLab CI/CD** - Непрерывная интеграция и доставка
- **GitHub Actions** - Автоматизация процессов
- **GitLab Pages** - Хостинг документации
- **GitHub Pages** - Хостинг приложения

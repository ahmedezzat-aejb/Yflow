<Warning>
This setup is only meant for personal use or testing. It runs on SQLite3 and an in-memory Redis queue, which supports only a single instance on a single machine. For production or multi-instance setups, you must use Docker Compose with PostgreSQL and Redis.
</Warning>

To get up and running quickly with Yflow, we will use the Yflow Docker image. Follow these steps:

## Prerequisites

You need to have [Git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git) and [Docker](https://docs.docker.com/get-docker/) installed on your machine in order to set up Yflow via Docker Compose.

## Install

### Pull Image and Run Docker image

Pull the Yflow Docker image and run the container with the following command:

```bash
docker run -d -p 8080:80 -v ~/.Yflow:/root/.Yflow -e AP_REDIS_TYPE=MEMORY -e AP_DB_TYPE=SQLITE3 -e AP_FRONTEND_URL="http://localhost:8080" Yflow/Yflow:latest
```

### Configure Webhook URL (Important for Triggers, Optional If you have public IP)

**Note:** By default, Yflow will try to use your public IP for webhooks. If you are self-hosting on a personal machine, you must configure the frontend URL so that the webhook is accessible from the internet.

**Optional:** The easiest way to expose your webhook URL on localhost is by using a service like ngrok. However, it is not suitable for production use.

1. Install ngrok
2. Run the following command:
```bash
ngrok http 8080
```
3. Replace `AP_FRONTEND_URL` environment variable in the command line above.

## Upgrade

Please follow the steps below:

### Step 1: Back Up Your Data (Recommended)

Before proceeding with the upgrade, it is always a good practice to back up your Yflow data to avoid any potential data loss during the update process.

1. **Stop the Current Yflow Container:** If your Yflow container is running, stop it using the following command:
   ```bash
   docker stop Yflow_container_name
   ```

2. **Backup Yflow Data Directory:** By default, Yflow data is stored in the `~/.Yflow` directory on your host machine. Create a backup of this directory to a safe location using the following command:
   ```bash
   cp -r ~/.Yflow ~/.Yflow_backup
   ```

### Step 2: Update the Docker Image

1. **Pull the Latest Yflow Docker Image:** Run the following command to pull the latest Yflow Docker image from Docker Hub:
   ```bash
   docker pull Yflow/Yflow:latest
   ```

### Step 3: Remove the Existing Yflow Container

1. **Stop and Remove the Current Yflow Container:** If your Yflow container is running, stop and remove it using the following commands:
   ```bash
   docker stop Yflow_container_name
   docker rm Yflow_container_name
   ```

### Step 4: Run the Updated Yflow Container

Now, run the updated Yflow container with the latest image using the same command you used during the initial setup. Be sure to replace `Yflow_container_name` with the desired name for your new container.

```bash
docker run -d -p 8080:80 -v ~/.Yflow:/root/.Yflow -e AP_REDIS_TYPE=MEMORY -e AP_DB_TYPE=SQLITE3 -e AP_FRONTEND_URL="http://localhost:8080" --name Yflow_container_name Yflow/Yflow:latest
```


Congratulations! You have successfully upgraded your Yflow Docker deployment
